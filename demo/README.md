# Demo

`menu.json` es el menú de ejemplo. Se valida con `pnpm validar:demo`.

Cada plato tiene su carpeta `demo/NN-slug/` (NN = orden, slug = `id` del plato):

- `input-cenital.jpg`, `input-45.jpg`, `input-lateral.jpg`: fotos desde arriba, a 45° y de costado.
- `ref.jpg`: imagen de referencia del plato terminado.
- `real.mp4` (opcional): video real del plato.
